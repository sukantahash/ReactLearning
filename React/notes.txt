- NPM vs NPX

=>          npm                                                     npx

-    Node Package Manager                                  Node Package Execute
-   Used for installing and managing packages            Running a package without installing globally
-   Install locally or globally (if -g used)            Temporarily runs  and clean up
-

    - npm install create-react-app
    => downloads and installs create-react-app into node_modules
        $ npm install -g create-react-app
        $ create-react-app my-app

    - npx create-react-app my-app
    => - Downloads latest version, runs directly without installing it permanaently
       - Cleaner and easier and preffered for one time tasks

What is Vite:
=> Vite (pronounced as veet) is a fast build tool and developmment server for modern web projects
    especially in react, Vue, vannila js

    - instant hot reload (HMR)
    - simple and minimal
    - work seamlessly with React, Vue, and more
    - Use Rollup under the hood for production builds

    Vite makes it fast and very easy to build and run web apps. Write code and see changes instantly

    Note: common use before vite was CRA (create-react-app), bundles js in webpack

    Issues with CRA:
        - slow startup time: bundles the whole app  in webpack before we can see it
        - slow hot reload
        - CRA hides a lot of configs behind the scene
